# RGT: GBRG-R10V-T1

## Status

This branch freezes the current seed-42 RGT mainline. It is a Japan4-cleanV3
validation result; Test remains untouched. RGT-alpha0.5 is intentionally not
promoted here because it is a single-seed, training-free checkpoint
interpolation candidate.

## Method identity

RGT is a training-deployment pipeline:

1. Train YOLO26n with the P4 RoadSnake geometric scaffold.
2. Add train-only, class-agnostic P3 GBRG region guidance.
3. Start one fresh 10-epoch native-loss consolidation from the best GBRG
   checkpoint.
4. Remove RoadSnake with T1 after training.
5. Evaluate/deploy the retained O2M predictions with score-weighted Box Voting.

RoadSnake and GBRG shape training. Box Voting is established post-processing,
not a claimed architectural contribution. Native R10 is a consolidation stage,
not a standalone module.

## Frozen protocol

- Data: Japan4-cleanV3 Val; Test sealed.
- Seed: 42.
- Native consolidation: exactly 10 epochs, fresh optimizer, no resume.
- Evaluation: image size 640, batch 32, workers 8, FP32, rect=True.
- Candidate path: O2M, confidence floor 0.001, class-aware NMS IoU 0.70,
  max_det 300, COCO maxDets 100.
- Aggregation: score-weighted Box Voting; coordinates change while class,
  score, count, and global order remain fixed.

## Unified results

| Model/view | AP | AP50 | AP75 | AP-small | AR100 | D40 AP75 |
|---|---:|---:|---:|---:|---:|---:|
| GBRG Native-R10 active + Voting | 0.27050 | 0.56142 | 0.22576 | 0.11907 | 0.53419 | 0.24037 |
| RGT-T1 + Voting | **0.27114** | **0.56192** | **0.22650** | **0.11937** | **0.53521** | **0.24108** |

Removing RoadSnake after consolidation improves AP by about 0.00064. This
supports the training-scaffold interpretation; it does not imply that
RoadSnake was ineffective during training.

## Boundary before deployment freeze

The T1 artifact still retains unused training/head state outside RoadSnake.
A later deployment-only artifact must jointly remove the GBRG region head and
O2O branches, prove raw O2M and Voting JSON equality, reload equality, and
unified COCO equality, then remeasure parameters, FLOPs, and same-hardware
latency. RGT also still requires a second controlled seed before a stability
claim.
